# AI 부트캠프 복습 퀴즈

AI 부트캠프에서 학습한 핵심 개념을 간단히 복습할 수 있는 웹 기반 객관식 퀴즈입니다. 별도의 서버나 빌드 과정 없이 브라우저에서 실행되며, 레트로 터미널과 픽셀 게임을 연상시키는 화면으로 구성되어 있습니다.

## 주요 기능

- 총 10개의 4지선다형 문제 제공
- 현재 문제 번호, 주제, 점수 표시
- 답안 선택 즉시 정답과 오답을 색상으로 구분
- 각 문제의 정답 및 해설 제공
- 답안 선택 전까지 다음 문제 버튼 비활성화
- 모든 문제 풀이 후 정답 수, 백분율 점수, 등급 표시
- `다시 풀기` 버튼을 이용한 퀴즈 재시작
- 작은 화면에서도 사용할 수 있는 반응형 레이아웃

## 퀴즈 주제

문제는 다음 영역을 다룹니다.

1. 파이썬 기초
2. 데이터 분석(pandas)
3. 머신러닝
4. 딥러닝
5. 생성형 AI 및 RAG

## 실행 방법

별도의 패키지 설치가 필요하지 않습니다.

1. 프로젝트 폴더에서 `index.html`을 웹 브라우저로 엽니다.
2. 보기 중 하나를 선택해 정답과 해설을 확인합니다.
3. `다음 문제` 버튼을 눌러 퀴즈를 계속 진행합니다.

로컬 웹 서버를 사용하려면 해당 폴더에서 다음 명령을 실행할 수도 있습니다.

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`에 접속합니다.

> 화면에 사용되는 `Press Start 2P` 글꼴은 Google Fonts에서 불러옵니다. 인터넷에 연결되어 있지 않으면 대체 글꼴인 `Courier New` 또는 브라우저의 고정폭 글꼴로 표시됩니다.

## 프로젝트 구조

```text
AI_Quiz/
├── index.html   # 퀴즈 화면의 HTML 구조
├── styles.css   # 레트로 터미널 테마 및 반응형 스타일
├── script.js    # 문제 데이터, 채점, 피드백, 결과 처리
└── README.md    # 프로젝트 안내 문서
```

## 사용 기술

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (`Press Start 2P`)

## 동작 방식

`script.js`의 `questions` 배열에 문제, 보기, 정답 인덱스, 해설이 저장됩니다. 사용자가 답을 선택하면 모든 보기가 잠기고 정답은 초록색, 선택한 오답은 붉은색으로 표시됩니다. 마지막 문제까지 완료하면 전체 정답률을 계산하고 점수에 따라 다음 등급을 보여 줍니다.

| 정답 수 | 등급 |
| --- | --- |
| 9~10개 | AI 마스터 |
| 7~8개 | AI 전문가 |
| 5~6개 | AI 실력자 |
| 0~4개 | AI 도전자 |

## 문제 추가 및 수정

문제를 변경하려면 `script.js`의 `questions` 배열을 수정합니다.

```javascript
{
  topic: "문제 주제",
  text: "문제 내용",
  choices: ["보기 1", "보기 2", "보기 3", "보기 4"],
  answer: 0,
  explanation: "정답 해설"
}
```

`answer`는 정답 보기의 배열 인덱스이므로 첫 번째 보기는 `0`, 두 번째 보기는 `1`로 지정합니다.
