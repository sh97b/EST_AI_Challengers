# 뽀모고치 (Pomogotchi)

뽀모고치는 포모도로 타이머와 다마고치 스타일의 펫 성장 요소를 결합한 웹 애플리케이션입니다. 25분 동안 집중하거나 짧은 테스트 타이머를 완료하면 펫이 경험치를 얻으며, 레벨업 보상으로 받은 보석으로 새로운 펫을 수집할 수 있습니다.

별도의 서버나 설치 과정 없이 HTML, CSS, JavaScript만으로 실행됩니다.

## 주요 기능

- **집중 타이머**: 25분 공부 모드와 기능 확인용 10초 테스트 모드를 제공합니다.
- **타이머 제어**: 시작, 일시정지, 이어하기, 초기화를 지원합니다.
- **펫 성장**: 타이머를 완료할 때마다 경험치 20을 획득하며, 레벨이 높아질수록 다음 레벨에 필요한 경험치가 증가합니다.
- **보석 보상**: 레벨업할 때마다 보석 5개를 획득합니다.
- **펫 수집**: 기본 펫인 강아지와 고양이를 사용할 수 있고, 보석으로 원숭이, 오리, 쥐를 영입할 수 있습니다.
- **주 펫 선택**: 공부방에 있는 보유 펫을 클릭해 주 펫으로 설정할 수 있습니다.
- **학습 기록**: 실제 공부 완료 횟수, 테스트 완료 횟수, 누적 집중 시간을 확인할 수 있습니다.
- **이름 설정**: 펫 이름을 최대 10자까지 지정하고 나중에 변경할 수 있습니다.
- **자동 저장**: 이름, 성장 기록, 보석, 보유 펫 등의 데이터가 브라우저에 저장됩니다.
- **반응형 UI**: 화면 크기에 따라 공부방과 정보 패널의 배치가 조정됩니다.

## 사용 방법

1. `index.html`을 웹 브라우저에서 엽니다.
2. 처음 나타나는 창에서 함께 공부할 펫의 이름을 입력합니다.
3. **정보** 탭에서 25분 공부 모드 또는 10초 테스트 모드를 선택합니다.
4. **공부 시작** 버튼을 눌러 타이머를 실행합니다.
5. 타이머를 끝까지 완료해 경험치를 얻고 펫을 성장시킵니다.
6. 레벨업으로 얻은 보석은 **펫** 탭에서 새로운 펫을 영입하는 데 사용할 수 있습니다.

공부 모드 완료 시 실제 공부 횟수와 누적 집중 시간 25분이 기록됩니다. 테스트 모드는 테스트 완료 횟수와 경험치만 반영하며 누적 집중 시간에는 포함되지 않습니다.

## 실행 방법

이 프로젝트는 빌드 과정이나 외부 패키지가 필요하지 않습니다.

### 파일을 직접 열기

`index.html`을 더블 클릭하거나 브라우저로 드래그해 실행합니다.

### 로컬 서버로 실행하기

프로젝트 폴더에서 다음 명령어를 실행한 뒤 `http://localhost:8000`에 접속합니다.

```bash
python -m http.server 8000
```

## 화면 구성

- **메인 탭**: 현재 펫 이름을 확인하고 변경합니다.
- **펫 탭**: 보유 중인 펫과 구매할 수 있는 펫을 확인합니다.
- **정보 탭**: 공부 모드, 타이머, 성장 상태, 학습 기록, 데이터 관리 메뉴를 제공합니다.
- **공부방**: 픽셀 아트 펫과 레벨, 경험치, 보석 현황을 표시합니다.

## 데이터 저장

게임 데이터는 브라우저의 `localStorage`에 `pomogotchi-save-v1` 키로 저장됩니다. 따라서 같은 브라우저에서 다시 접속하면 진행 상황이 유지됩니다.

- **성장 기록 지우기**: 레벨, 경험치, 공부 및 테스트 완료 횟수, 누적 집중 시간을 초기화합니다.
- **게임 데이터 모두 지우기**: 펫 이름과 저장된 진행 정보를 삭제하고 처음 화면으로 돌아갑니다.

브라우저 사이트 데이터를 삭제하거나 다른 브라우저 또는 기기를 사용하면 기존 기록은 이어지지 않습니다. 실행 중인 타이머의 남은 시간은 저장되지 않습니다.

## 기술 스택

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API (픽셀 펫 렌더링)
- Web Storage API (`localStorage`)

## 파일 구조

```text
Pomogotchi/
├── index.html   # 웹 페이지 구조
├── style.css    # 레이아웃, 픽셀 아트 스타일, 반응형 디자인
├── script.js    # 타이머, 성장 시스템, 펫 관리, 데이터 저장 로직
└── README.md    # 프로젝트 설명
```

## 참고 사항

- 모든 데이터는 서버가 아닌 현재 브라우저에만 저장됩니다.
- 타이머가 완료되어야 경험치와 완료 기록이 반영됩니다.
- 타이머 실행 중 모드를 변경하면 진행 중이던 타이머가 종료되고 선택한 모드의 초기 시간으로 돌아갑니다.
